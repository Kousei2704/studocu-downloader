# StuDocu PDF Downloader

A simple, open-source CLI tool to bypass paywalls and download StuDocu documents as high-quality PDFs. Built with Python and Playwright to automatically handle page lazy-loading and blur filters.

## Requirements
* Python 3.8+
* Playwright

## Installation

```bash
git clone [https://github.com/yourusername/studocu-downloader.git](https://github.com/yourusername/studocu-downloader.git)
cd studocu-downloader
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
playwright install
